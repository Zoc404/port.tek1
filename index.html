Numerical Question Types
T-1
Simply Supported Beam — Uniform EI, Standard Load
Double Integration Method · Moment Area Method
Low · 2 Qs
Core Concept
Standard simply supported beam with ONE load type (single point load OR full-span UDL). EI is constant throughout. Find slope at supports and/or deflection at mid-span or any point. This is the foundational type — all other types build on it.
Methods Used
Double Integration Moment Area Theorem Conjugate Beam (alternate)
Key Formula
// Double Integration EI·d²y/dx² = M(x) EI·dy/dx = ∫M(x)dx + C₁ ← slope equation EI·y = ∫∫M(x)dx + C₁x + C₂ ← deflection equation // Boundary Conditions for SSB y = 0 at x = 0 → C₂ = 0 y = 0 at x = L → solve for C₁ // Standard Results (memorize) θ_max = PL²/16EI δ_max = PL³/48EI (central point load) θ_max = wL³/24EI δ_max = 5wL⁴/384EI (full UDL)
How to Recognize in Exam
You see this type when: SSB with single clean load, no overhangs, no internal hinges, EI = constant.
  • Question asks: slope at A, slope at B, deflection at centre/midspan, or deflection at any single x
  • One M(x) expression covers the whole span without breaks
  • Integrate twice → apply two BCs → done
Sub-Variations
Symmetric loading, find θ_A
Rotation at A only (moment area)
Deflection at centre
Both slope and deflection at same point

T-2
Multiple / Partial Loads — Macaulay's Method
Double Integration with Bracket Notation · Discontinuous Loading
Medium · 1 Q
Core Concept
SSB or overhanging beam with more than one point load, OR a UDL that does NOT cover the full span. A single clean M(x) cannot be written — Macaulay's bracket notation ⟨x−a⟩ handles each load discontinuity in ONE unified equation, so integration is done only once.
Methods Used
Macaulay's Method Double Integration Partial UDL Extension Trick
Key Formula & Rules
// General Macaulay equation (section at extreme right X-X) EI·d²y/dx² = R_A·x − P₁⟨x−a⟩ − P₂⟨x−b⟩ − (w/2)⟨x−c⟩² + (w/2)⟨x−d⟩² // PARTIAL UDL TRICK — for UDL from x=c to x=d only: Extend UDL to right end → then add equal+opposite UDL from x=d This gives: −(w/2)⟨x−c⟩² + (w/2)⟨x−d⟩² // Rules: Rule 1: NEVER drop bracket terms mid-integration Rule 2: Only substitute x AND drop terms where ⟨x−a⟩ < 0 at FINAL step Rule 3: Point load → ⟨x−a⟩¹, UDL → ⟨x−a⟩², Moment → ⟨x−a⟩⁰
How to Recognize in Exam
You see this type when: multiple point loads at different positions, OR UDL over part of span only.
  • Keywords: "UDL over middle third", "concentrated loads at 1m, 4m, 7m", "two point loads"
  • Cannot write single M(x) — must section at extreme right end
  • Usually asks: deflection at mid-span or at load point
Sub-Variations
Partial UDL (middle ⅓ of span)
Two or more point loads
UDL + point loads combined
Overhang with multiple loads
End moment + point load

T-3
Stepped / Varying EI Beam — M/EI Diagram Method
Moment Area · Conjugate Beam · EI changes span-to-span
★ High · 5 Qs
Core Concept
Beam has different flexural stiffness in different spans — e.g. 3EI, 2EI, EI. You CANNOT use a uniform M/EI. Each span's bending moment ordinate must be divided by its own local EI to get the M/EI ordinate. In later questions (Q14, Q16), E and cross-section dimensions are given numerically — you must compute I = bd³/12 first, then EI in kN·m².
Methods Used
Moment Area Theorem 1 & 2 Conjugate Beam (verification) M/EI diagram (piecewise)
Key Formula
// M/EI ordinate — use LOCAL EI of that span Ordinate = M(x) ÷ local EI of that span → span with 2EI: ordinate = M / 2EI (half the value!) → span with 3EI: ordinate = M / 3EI // When numerical E, b, d given: I = bd³ / 12 (in mm⁴ → convert to m⁴: ×10⁻¹²) EI = E × I (in kN·m²) // Moment Area Theorem 2: Δ_B/A = Σ( Area_i × x̄_i ) about point B θ_A = Δ_B/A / L // Centroid of standard shapes: Triangle: x̄ = L/3 from taller end Parabola (UDL): x̄ = 3L/8 from taller end, area = (2/3)bh
How to Recognize in Exam
Keywords: "EI", "2EI", "3EI" labeled on beam diagram — OR numerical values of E (in N/mm²) + b×d given.
  • Beam is drawn with different stiffness labels for different portions
  • OR: "Take E = 12600 N/mm², consider 350mm wide 500mm deep beam"
  • Always compute I = bd³/12 first when dimensions are given
  • Draw M/EI diagram SEPARATELY for each span segment
Sub-Variations
2-span: EI + 2EI
3-span: 3EI + 2EI + EI
Symmetric: I + 2I + I
Numerical E + I (compute I first)
Find slope at A only
Find both slope + deflection
Answer in mm (convert ×1000)

T-4
Overhang Beam — Slope & Deflection at Free End
Conjugate Beam Method · Free End Analysis
★ High · 4 Qs
Core Concept
Beam extends beyond one or both supports (overhang). The overhanging portion behaves like a cantilever. In the conjugate beam method: the free end of the real beam remains a free end in the conjugate beam — it carries M/EI load but has NO support. Slope at free end = shear in conjugate beam at that point. Deflection at free end = moment in conjugate beam at that point.
Methods Used
Conjugate Beam Method Moment Area (verification) Superposition (for complex loads)
Key Formula & Support Conversion
// Conjugate Beam Support Conversion Rules: Real beam Pin → Conjugate beam Pin Real beam Roller → Conjugate beam Roller Real beam Fixed → Conjugate beam Free end ← (they swap!) Real beam Free → Conjugate beam Fixed end ← (they swap!) // For overhang: free end stays free in conjugate beam // (overhang free end is NOT a fixed end) // At free end C of conjugate beam: θ_C = V'_C (shear in conjugate beam at C) Δ_C = M'_C (moment in conjugate beam at C) // Sign: −ve M' → downward deflection (sagging is +ve)
How to Recognize in Exam
Keywords: "beam with overhang", "free end", "deflection at C (free end)", diagram shows beam extending past a support.
  • Overhang part of BMD is usually negative (hogging) — triangular shape
  • Conjugate beam has M/EI load on overhang part but no tip support
  • Take moment about supports to find R'_A, R'_B, then cut section at C
Sub-Variations
UDL on overhang portion only
Point load at free end
Varying UDL on overhang
Deflection at midpoint of span (not free end)
Stepped EI + overhang combined
Slope AND deflection both required

T-5
Compound Beam with Internal Hinge — Conjugate Beam FBD Split
Most Repeated Pattern · Superposition + FBD Analysis of Conjugate Beam
★★ Very High · 7 Qs
Core Concept
Beam has one or more internal hinges connecting multiple spans. Cannot be analysed as a single beam. In the conjugate beam: internal hinges remain as internal hinges. The compound conjugate beam is split at each hinge into separate FBDs (A'B', B'C', C'D' etc.) and each FBD is analysed independently using equilibrium. This is the single most-repeated question type in PU exams — appears in 7 out of 17 questions.
Methods Used
Conjugate Beam (primary) Moment Area (verification) Superposition FBD Equilibrium at Hinges
Key Principle & Formula
// At internal hinge in conjugate beam — CRITICAL: M' = 0 (moment in conjugate beam at hinge = 0) // This is the KEY equation. Use ΣM=0 about the hinge to find unknowns. // V' transfers between parts (NOT zero at hinge): V'_left ≠ V'_right at hinge (there is shear transfer) // FBD procedure for each part: ΣM = 0 → solve for internal forces at hinge ΣFy = 0 → find V' values // At any point in conjugate beam: Slope = V' (shear at that section) Deflection = M' (moment at that section) // Conjugate beam support conversion: Pin/Roller → unchanged Internal hinge → remains internal hinge Fixed → Free, Free → Fixed
How to Recognize in Exam
Instantly recognizable: beam diagram shows a small circle (∘) symbol at one or more intermediate points — that is an internal hinge.
  • Beam has 2 or more spans connected by hinges
  • Keywords: "internal hinge at B", "compound beam", "Gerber beam"
  • Superposition usually needed to split complex loads into manageable sub-beams
  • Always draw full M/EI diagram FIRST before splitting into FBDs
Step-by-Step Solving Order
01Superposition if needed: Split complex loading into 2 simple sub-beams. Find reactions for each part separately.
02Draw full BMD for the complete compound beam. Mark +ve (sagging) and −ve (hogging) regions clearly.
03Draw M/EI diagram — divide each BMD ordinate by local EI if stepped, otherwise by uniform EI.
04Draw conjugate beam with same M/EI as distributed load. Keep internal hinges exactly as in real beam.
05Detach at internal hinges → separate FBDs (A'B', B'C', C'D'). Each FBD has its own unknown shear and moment at the cut.
06For each FBD: ΣM=0 about hinge point (using M'=0 condition) → find unknowns. Then ΣFy=0 → find V'.
07Read results: Slope at any point = V' at that section. Deflection at any point = M' at that section in conjugate beam.

Design / Reverse Problem — Find Unknown Load for Deflection Limit
Symbolic Analysis · Back-Calculation · Both Methods Required
Rare · 1 Q
Core Concept
A deflection LIMIT is specified (e.g. Δ_C ≤ 100mm). The UDL intensity w is unknown. You perform the full conjugate beam or moment area analysis symbolically — keeping w in all expressions — to get Δ_C = f(w). Then set f(w) = limit and solve for w. This is the only "design" question type in this chapter.
Key Formula
// Express deflection symbolically in terms of w: Δ_C = 225w / 128EI (derived from conjugate beam analysis) // Set equal to limit (convert mm → m first!): 100 mm = 0.1 m // Back-calculate: 0.1 = 225w / (128 × 4000) w = 0.1 × 128 × 4000 / 225 = 227.56 kN/m

Theory / Short Answer Questions
Prove that shear force at any section of a conjugate beam equals the slope at the corresponding section of the real beam.
2015 Fall · Derivation
TopicConjugate Beam Theory — Proof of Analogy
ConceptThe elastic curve equation EI d²y/dx² = M is mathematically identical to the conjugate beam equilibrium equation dV'/dx = −w' where w' = M/EI. Hence V' ↔ slope, M' ↔ deflection.
Exam hintStart from Euler-Bernoulli beam equation. Show differential equation for elastic curve matches equilibrium equation for conjugate beam. State the analogy table clearly.

Theorem 1The change in slope between two points A and B = Area of M/EI diagram between A and B.
Theorem 2The tangential deviation of B from tangent at A = First moment of M/EI area between A and B, taken about B.

Explain the conjugate beam method. State the support conversion rules.
Conceptual — base theory
TopicConjugate Beam Method — Concept + Support Rules
ConceptA fictitious beam (conjugate) is loaded with the M/EI diagram of the real beam. Shear in conjugate beam = slope in real beam. Moment in conjugate beam = deflection in real beam.
Support rulesPin→Pin · Roller→Roller · Fixed→Free · Free→Fixed · Internal Hinge→Internal Hinge

State Macaulay's method. What is the advantage over the double integration method for discontinuous loads?
Short answer type
TopicMacaulay's Method — Concept and Advantage
ConceptUses ⟨x−a⟩ bracket notation to write a SINGLE bending moment equation valid for the entire beam, regardless of load discontinuities. Integration is performed only once.
AdvantageFor multiple loads or partial UDL, double integration requires separate M(x) for each region and matching boundary conditions at each junction. Macaulay's avoids this entirely with one equation.
Exam hintState the bracket rule: ⟨x−a⟩ = 0 when x < a, and = (x−a) when x ≥ a. Give a short example with one point load.

⚠️Trap Questions — Common Student Mistakes
  • !Using uniform EI on stepped beam (Type 3): Divide each span's BM by its OWN local EI — not a single EI. This mistake loses all marks for M/EI diagram.
  • !Conjugate beam support at free end of overhang: Students wrongly think free end becomes fixed. For overhang free end — it stays free (NOT fixed). Fixed↔Free only applies to cantilever base/tip.
  • !Dropping Macaulay brackets mid-integration: Rule is absolute — keep ALL bracket terms through both integrations. Only drop (set =0) when substituting the final x value at the very last step.
  • !Setting V'=0 at internal hinge (Type 5): Moment M' = 0 at hinge (not shear). Shear V' transfers and is definitely NOT zero. This is the most common conceptual error in Type 5.
  • !Unit conversion in numerical EI questions: E in N/mm² must be converted to kN/m² (×10³). I in mm⁴ must be converted to m⁴ (×10⁻¹²). Forgetting conversion gives EI off by factor of 10⁹.
  • !Not converting final deflection to mm: Q14 and Q16 ask for answer in mm. Deflection from formula is in metres — multiply by 1000. Forgetting this loses the final mark.
